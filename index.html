Tutorial Penggunaan Git bersama Radnet Digital Indonesia

1. Inisialisasi repository Git menggunakan perintah "git init"

2. Membuat folder, beri nama Tutorial_Git

3. Membuat file, beri nama Index.html. Edit file tersebut.

4. Lakukan perintah "git status" untuk melihat status repository.

5. Lakukan perintah "git add" untuk menambahkan file ke staging area. Kemudian lakukan "git status" kembali untuk mengecek apakah sudah berhasil menambahkan perubahan yang dilakukan.

6. Lakukan perintah "git commit -m 'pesan commit'" untuk menyimpan perubahan yang telah dilakukan.

7. Lakukan perintah "git remote add origin 'URL_repository' " untuk menambahkan remote repository.

8. Lakukan perintah "git push -u origin main" untuk mengunggah perubahan ke remote repository.
